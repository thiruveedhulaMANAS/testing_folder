    ↓

    ↓
KnowledgebaseSegmentation.txt (discount_caps by segment × price_sensitivity)
    ↓
Offer.txt (customer_id, segment, intent, recommendation, offer_details, campaign_plan, compliance_validation)

Transformation Logic:
1. Read customer_360.csv → Extract customer_id, email, profile data
2. Read segmentation_results.csv → Map customer_id to loyalty_tier, price_sensitivity_band
3. Read Intent.csv → Map customer_id to primary_interest, intent_level
4. Read Recommendation.txt → Map customer_id to next_best_product, product_details
5. Read campaign_details.txt → Extract campaign_name, discount_rate (20%)
6. Read KnowledgebaseOffer.txt → Extract approved_channels, frequency_caps, blackout_rules
7. Read KnowledgebaseSegmentation.txt → Extract discount_caps by segment × price_sensitivity
8. For each customer:
   a. If no recommendation → BLOCK OFFER (log reason)
   b. If recommendation exists:
      - Validate discount_rate ≤ segment discount_cap
      - Select channels from approved_channels list
      - Check blackout/frequency rules
      - If all validations pass → APPROVE OFFER
      - If any validation fails → BLOCK OFFER (log reason)
9. Write Offer.txt with customer_id, segment, intent, recommendation, offer_details, campaign_plan, compliance_validation

- Output: customer_id only (no direct PII)
